# 职途前端 V2 原型

这是一个与现有 Vue 应用隔离的静态交互原型，用于确认产品信息架构和视觉方向。

## 查看方式

在项目根目录执行：

```powershell
python -m http.server 4173 --directory docs/prototypes/career-platform-v2
```

浏览器打开：`http://127.0.0.1:4173`

## 可交互内容

- 顶部“行业全景 / 职业分析”导航。
- 头像进入个人资料，余额进入钱包。
- 职业分析和 AI 对话扣费确认。
- PDF 简历文件选择、解析结果全选和资料保存。
- 充值金额选择。
- 桌面端和移动端响应式布局。

所有数据、价格和分析结果均为原型演示，不代表最终业务规则。
