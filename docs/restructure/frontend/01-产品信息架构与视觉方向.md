# 前端产品信息架构与视觉方向

## 1. 设计目标

前端从“多个 AI 功能页面”调整为：

```text
市场数据首页 + 职业规划 Agent 工作台
```

聊天只是输入方式，真正的产品核心是：

- 职业画像。
- 真实市场证据。
- 候选方向比较。
- 能力差距。
- 可执行行动计划。

## 2. 主导航

建议主导航收敛为：

```text
市场洞察
职业 Agent
推荐岗位
我的计划
个人中心
```

旧页面暂时保留，但逐步从主导航弱化：

```text
/major-analysis
/career-compass
/compare/cities
/compare/industries
```

它们最终应成为 Agent 内部工具或结果详情，而不是用户必须理解的功能分类。

## 3. 首页定位

首页只负责客观市场数据，不负责长篇 AI 生成。

### 首屏

首屏包含：

- 产品定位文案。
- 自然语言 Agent 输入框。
- 岗位总量、热门方向或薪资等核心市场数字。
- 常用问题快捷入口。

输入示例：

```text
说说你的专业、技能、经历或职业困惑……
```

快捷问题：

```text
我是计算机专业，不知道适合什么岗位
想从运营转产品经理
比较杭州和上海的前端机会
分析我的技能还缺什么
```

用户提交后直接进入 `/agent/:conversationId`，首页不执行完整 Agent 运行。

### 市场数据区

保留：

- 岗位总量和趋势。
- 热门行业和城市。
- 薪资分布。
- 技能需求。
- 学历和经验要求。
- 数据更新时间和样本量。

每张数据卡增加：

```text
数据来源
样本数量
统计时间
让 Agent 解读
```

“让 Agent 解读”只传递当前筛选条件和数据上下文，不在首页复刻一套聊天流程。

## 4. Agent 工作台定位

Agent 页面应像职业决策驾驶舱，而不是通用聊天机器人。

桌面端：

```text
[会话列表] [消息和实时分析] [画像/证据/行动计划]
```

移动端：

```text
[会话抽屉] [消息和分析] [底部输入框]
[画像/证据/计划折叠面板]
```

## 5. 视觉方向

推荐“数据研究终端 + 职业导航”的视觉语言：

- 低饱和灰白或深墨蓝背景。
- 深靛蓝作为主色。
- 青绿表示完成和可信数据。
- 琥珀表示等待确认或数据降级。
- 红色只表示失败或危险操作。
- 适度圆角和阴影，避免所有内容都是大卡片。
- 减少紫色渐变、玻璃拟态、机器人头像和无意义光效。

状态颜色：

```text
分析中：蓝色
数据完成：青绿色
等待用户：琥珀色
降级数据：橙色
失败：红色
```

## 6. 结果呈现原则

Agent 结论必须支持展开证据：

```text
样本量：426 个岗位
数据时间：2026-07-20
数据来源：职位库
筛选条件：杭州、数据分析、应届
```

不要展示：

- 模型完整思考过程。
- Prompt、SQL、ES DSL。
- 内部异常堆栈。
- 没有依据的精确匹配分数。
