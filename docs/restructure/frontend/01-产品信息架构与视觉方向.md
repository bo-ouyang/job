# 前端产品信息架构与视觉方向

## 原型基线

本文以以下原型和产品说明为准：

```text
ChatGPT Image 2026年7月20日 17_50_23 (1).png
    首页：大学生职业规划数据总览

ChatGPT Image 2026年7月20日 17_50_24 (2).png
    Agent：AI 职业规划 Agent

大学生职业规划与数据分析 Agent UI 原型产品说明文档.docx
```

产品名称暂定为 **职途AI**。

```text
首页 = 职业数据分析总览
Agent 页 = AI 对话 + 用户资料 + 职业分析结果 + 行动计划
```

## 1. 设计目标

前端从“多个 AI 功能页面”调整为：

```text
市场数据首页 + 职业规划 Agent 工作台
```

聊天只是输入方式，真正的产品核心是：

- 职业画像。
- 真实市场证据。
- 候选方向比较。
- 能力差距。
- 可执行行动计划。

## 2. 主导航

原型确定的主导航为：

```text
首页
职业数据
规划 Agent
院校趋势
技能地图
我的报告
设置
```

旧页面暂时保留，并按以下关系迁移：

```text
/major-analysis
/career-compass
/compare/cities
/compare/industries

major-analysis -> 职业数据或规划 Agent 内部分析
career-compass -> 规划 Agent
compare/cities -> 职业数据详情
compare/industries -> 职业数据详情
我的报告 -> Agent 生成的历史规划和报告
```

它们最终应成为 Agent 内部工具或结果详情，而不是用户必须理解的功能分类。

## 3. 首页定位

首页只负责客观市场数据，不负责长篇 AI 生成。

原型首页标题：

```text
大学生职业规划数据总览
```

副标题：

```text
洞察专业趋势，发现职业方向，掌握薪资走势与技能需求，科学规划未来
```

### 首屏

首屏包含：

- 产品定位文案。
- 全局岗位、行业、技能和报告搜索框。
- 岗位总量、平均起薪、增长行业和个人方向匹配度。
- 轻量职业数据插画。

首页不执行完整 Agent 对话。用户通过首页 CTA 或“让 Agent 解读”进入 `/agent/:conversationId`。

### 市场数据区

保留：

- 岗位总量和趋势。
- 热门行业和城市。
- 薪资分布。
- 技能需求。
- 学历和经验要求。
- 数据更新时间和样本量。

原型首页第一屏固定展示四张 KPI 卡：

```text
热门岗位数
平均起薪
增长最快行业
匹配度评分（我的方向）
```

每张数据卡增加：

```text
数据来源
样本数量
统计时间
让 Agent 解读
```

“让 Agent 解读”只传递当前筛选条件和数据上下文，不在首页复刻一套聊天流程。

首页模块顺序以原型为准：

1. 标题、副标题和轻量数据插画。
2. 四张核心指标卡。
3. 行业发展趋势折线图。
4. 不同职业方向平均起薪横向柱状图。
5. 技能需求分布环形图。
6. 专业与职业匹配度热力图。
7. 热门职业排行榜。
8. 适合你的热门方向、本周趋势观察、AI 洞察摘要。
9. 进入职业规划 Agent CTA。

“匹配度评分”和个性化推荐依赖用户资料。资料未完成时显示资料完成度和引导，不显示伪造的个性化结论。

## 4. Agent 工作台定位

Agent 页面应像职业决策驾驶舱，而不是通用聊天机器人。

原型页面标题为 `AI 职业规划 Agent`，副标题为：

```text
基于你的兴趣、能力与目标，AI 为你生成个性化职业路径与行动建议，陪你规划精彩未来
```

桌面端：

```text
[会话列表] [消息和实时分析] [画像/证据/行动计划]
```

移动端：

```text
[会话抽屉] [消息和分析] [底部输入框]
[画像/证据/计划折叠面板]
```

## 5. 视觉方向

原型视觉基线为现代 AI SaaS 产品：

- 浅灰蓝页面背景，白色卡片为主。
- 蓝色、青蓝色和蓝紫色渐变作为品牌视觉。
- 卡片圆角约 12px 至 20px。
- 使用柔和阴影、充足留白、线性图标和轻量 AI 插画。
- 蓝紫渐变和机器人插画只用于品牌区域、CTA 和重点模块，不能影响数据阅读。

状态颜色：

```text
分析中：蓝色
数据完成：青绿色
等待用户：琥珀色
降级数据：橙色
失败：红色
```

## 6. 结果呈现原则

Agent 结论必须支持展开证据：

```text
样本量：426 个岗位
数据时间：2026-07-20
数据来源：职位库
筛选条件：杭州、数据分析、应届
```

不要展示：

- 模型完整思考过程。
- Prompt、SQL、ES DSL。
- 内部异常堆栈。
- 没有依据的精确匹配分数。

## 7. 尺寸基线

```text
页面标题：28px-36px，加粗，深蓝黑色
模块标题：16px-20px，半粗体
正文：13px-16px
辅助说明：12px-14px，灰色
核心数据：24px-32px，加粗
桌面内容宽度：1440px 或更宽
侧边栏宽度：约 220px
```
