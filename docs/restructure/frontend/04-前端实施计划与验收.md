# 前端实施计划与验收

## 原型实现边界

本计划以“职途AI”首页和 Agent 高保真原型为准，优先实现桌面端 1440px 体验，再适配平板和移动端。

首页必须完成职业数据总览的主要模块；Agent 页必须完成对话、背景资料、推荐方向和行动结果的复合布局，不能先做成单栏聊天页。

## 4. 验收标准

- 用户不需要选择旧 AI 功能即可输入职业问题。
- Agent 页面可展示运行过程和最终结构化结果。
- SSE 重连不会重复发送用户消息或创建 AgentRun。
- 刷新页面可以恢复运行状态。
- 事件异常不会崩溃整个页面。
- 旧 AI 任务面板和 WebSocket 消息仍然可用。
- `npm run build` 成功。
- 移动端没有横向滚动、输入框遮挡或导航重叠。
- 首页包含四张 KPI 卡、趋势折线图、起薪柱状图、技能环形图、匹配热力图、热门职业排行、个性化推荐和 Agent CTA。
- Agent 页包含对话、用户背景、资料上传、推荐方向、成长路线、技能差距、实习推荐、职业路径、周任务和岗位推荐。
- 所有 AI 生成内容显示“仅供参考，请结合自身情况判断”提示。
