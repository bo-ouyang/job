# 前端组件、状态与路由设计

## 1. 路由

新增：

```text
/agent
/agent/:conversationId
```

路由元信息：

```js
meta: {
  requiresAuth: true,
  feature: "agent"
}
```

后端仍是最终权限判断，前端路由守卫只负责用户体验和隐藏入口。

## 2. API 模块

新增：

```text
frontend/src/api/agent.js
frontend/src/utils/sseClient.js
```

`agent.js` 提供：

```text
createConversation
listConversations
getConversation
sendMessage
getRun
cancelRun
```

`sseClient.js` 负责：

- fetch 流读取。
- Bearer Header。
- `id/event/data` 解析。
- heartbeat。
- AbortController。
- 最后事件 ID。
- 重连退避。
- 解析错误隔离。

不要把 SSE 放入现有 Axios `request.js`，长连接不适合现有五秒请求超时和响应拦截器。

## 3. Pinia store

新增：

```text
frontend/src/stores/agent.js
```

状态：

```text
conversations
activeConversation
messages
activeRun
runEvents
careerProfileDraft
connectionState
lastEventSequence
reconnectAttempt
isSending
error
```

Actions：

```text
loadConversations()
openConversation(id)
createConversation()
sendMessage(content)
startRunStream(runId)
handleEvent(event)
recoverRun(runId)
reconnectRunStream()
cancelRun()
resetActiveConversation()
```

Store 不变量：

- 一个运行只有一个活动 SSE 连接。
- 事件按 ID 或 sequence 去重。
- 终态后清理重连定时器。
- 刷新恢复先加载会话，再恢复运行。
- 持久化状态必须按用户隔离。
- `aiTask.js` 继续维护旧 AI 任务，不与 Agent 状态合并。

## 4. 组件目录

```text
frontend/src/components/agent/
├── AgentShell.vue
├── ConversationList.vue
├── ConversationListItem.vue
├── MessageTimeline.vue
├── MessageBubble.vue
├── MessageComposer.vue
├── RunStatusPanel.vue
├── ToolExecutionCard.vue
├── ClarificationCard.vue
├── CareerProfileCard.vue
├── DirectionCard.vue
├── MarketEvidenceCard.vue
├── ActionPlanCard.vue
└── AgentErrorState.vue
```

职责：

- `AgentShell`：三栏布局和移动端布局。
- `ConversationList`：会话列表、创建、归档。
- `MessageTimeline`：消息、工具状态、追问和增量回答。
- `MessageComposer`：输入、提交、停止。
- `RunStatusPanel`：运行状态、耗时、重连和取消。
- 结果卡：画像、方向、证据和行动计划。

## 5. 页面

```text
frontend/src/views/AgentWorkspace.vue
frontend/src/views/AgentConversation.vue
```

推荐由 `AgentWorkspace` 负责空状态和会话列表，由 `AgentConversation` 负责具体会话和运行。

## 6. 现有文件改造

```text
frontend/src/router/index.js
frontend/src/layout/BasicLayout.vue
frontend/src/assets/main.css
```

保留不变：

```text
frontend/src/stores/aiTask.js
frontend/src/components/AiTaskPanel.vue
frontend/src/api/ai.js
```

它们在旧 AI 下线前继续运行。

## 7. 设计约束

- 不在一个 Vue 文件中实现完整工作台。
- 不将模型内部推理渲染给用户。
- 不依赖前端传入的职业画像作为权限事实。
- 所有结构化结果都允许空数据和错误状态。
- SSE 事件解析失败不能导致整个会话页面崩溃。
