## 1. 路由

新增：

```text
/agent
/agent/:conversationId
```

原型对应的页面入口：

```text
/       大学生职业规划数据总览
/agent  AI 职业规划 Agent
```

路由元信息：

```js
meta: {
  requiresAuth: true,
  feature: "agent"
}
```

后端仍是最终权限判断，前端路由守卫只负责用户体验和隐藏入口。

## 2. API 模块

新增：

```text
frontend/src/api/agent.js
frontend/src/utils/sseClient.js
```

`agent.js` 提供：

```text
createConversation
listConversations
getConversation
sendMessage
getRun
cancelRun
```

`sseClient.js` 负责：

- fetch 流读取。
- Bearer Header。
- `id/event/data` 解析。
- heartbeat。
- AbortController。
- 最后事件 ID。
- 重连退避。
- 解析错误隔离。

不要把 SSE 放入现有 Axios `request.js`，长连接不适合现有五秒请求超时和响应拦截器。

## 3. Pinia store

新增：

```text
frontend/src/stores/agent.js
```

状态：

```text
conversations
activeConversation
messages
activeRun
runEvents
careerProfileDraft
connectionState
lastEventSequence
reconnectAttempt
isSending
error
```

Actions：

```text
loadConversations()
openConversation(id)
createConversation()
sendMessage(content)
startRunStream(runId)
handleEvent(event)
recoverRun(runId)
reconnectRunStream()
cancelRun()
resetActiveConversation()
```

Store 不变量：

- 一个运行只有一个活动 SSE 连接。
- 事件按 ID 或 sequence 去重。
- 终态后清理重连定时器。
- 刷新恢复先加载会话，再恢复运行。
- 持久化状态必须按用户隔离。
- `aiTask.js` 继续维护旧 AI 任务，不与 Agent 状态合并。

```

现有 `HomeView.vue` 应逐步拆为首页区块组件，避免继续成为单一大型 View。图表统一封装加载、空数据、错误、更新时间和来源信息。

```

## 7. 设计约束

- 不在一个 Vue 文件中实现完整工作台。
- 不将模型内部推理渲染给用户。
- 不依赖前端传入的职业画像作为权限事实。
- 所有结构化结果都允许空数据和错误状态。
- SSE 事件解析失败不能导致整个会话页面崩溃。
- 原型阶段允许使用模拟数据，但组件必须标记数据来源和“AI 生成，仅供参考”提示。
- 匹配度、薪资和趋势没有数据时不得显示为真实结论。
- 首页和 Agent 页必须共享侧边栏、顶栏、颜色、卡片和状态设计系统。
